# Yeve Echo 评委演示数据总览

## 1. 目标

这套数据用于让后端每次启动后恢复到相同、可演示的初始状态，保证评委能够稳定看到完整产品闭环：

1. 以固定匿名身份进入产品。
2. 在海洋中浏览较深的情绪表达。
3. 在天空中接住轻盈、短暂的念头。
4. 点亮心意并留下仅作者可见的留言。
5. 在“我的”页面看到浏览量、心意、留言和开发组回信。
6. 在森林中看到已开启、可开启、长期锁定三类时间胶囊。
7. 现场创建 1 分钟胶囊，演示等待和开启。
8. 展示灵笺对话与人格画像。
9. 条件允许时展示 Soul Agent 匹配。

## 2. 数据规模

| 集合 | 建议数量 | 用途 |
|---|---:|---|
| users | 10 | 一个主演示身份、一个辅助身份、八个内容作者 |
| bottles | 10 | 海洋深度内容池 |
| planes | 10 | 天空轻量内容池 |
| likes | 76 | 让内容呈现自然活跃度 |
| comments | 28 | 展示一次性、私密的陌生人善意 |
| capsules | 4 | 预置已开启、待开启、长期锁定、即将开启四种状态 |
| echo_conversations | 1 | 主身份的灵笺会话 |
| echo_messages | 10 | 五轮用户与 AI 对话 |
| echo_profiles | 1 | 可立即展示的人格画像 |
| agent_profiles | 4 | Yeve、Kai、Luna、Sora |
| agent_matches | 1 | 固定匹配结果 |
| agent_dialogues | 1 | 主推 Yeve 与 Kai 的代理对话 |

## 3. 稳定标识约定

所有预置数据使用稳定 ID，不能在每次启动时随机生成，否则点赞、评论、画像等关联关系会断裂。

| 类型 | ID 示例 |
|---|---|
| 用户 | `demo_user_main`、`demo_user_wind` |
| 浮笺 | `demo_bottle_01` |
| 飞笺 | `demo_plane_01` |
| 心意 | `demo_like_bottle_01_01` |
| 留言 | `demo_comment_bottle_01_01` |
| 胶囊 | `demo_capsule_opened` |
| 灵笺会话 | `demo_echo_conversation_main` |
| 灵笺消息 | `demo_echo_message_01` |

## 4. 时间生成规则

不要把所有时间写成固定日期。每次初始化时，以后端启动时间 `now` 为基准生成：

| 场景 | 时间规则 |
|---|---|
| 最近内容 | `now - 35 分钟` |
| 昨日内容 | `now - 1 天 3 小时` |
| 较早内容 | `now - 3～12 天` |
| 已开启胶囊 | `created_at = now - 365 天`，`unlock_at = now - 2 天`，`opened_at = now - 1 天` |
| 当前可开启胶囊 | `created_at = now - 30 天`，`unlock_at = now - 5 分钟`，`opened_at = null` |
| 长期锁定胶囊 | `created_at = now - 2 天`，`unlock_at = now + 363 天` |
| 即将开启胶囊 | `created_at = now - 50 秒`，`unlock_at = now + 10 秒` |

所有时间统一写为带 UTC 时区的 ISO 8601 字符串，例如 `2026-07-24T12:00:00+00:00`。

## 5. 内容原则

- 海洋内容偏长，表达完整但不写成作文。
- 天空内容偏短，像偶然接住的一句话。
- 留言只提供一次善意，不引导关注、私聊或交换联系方式。
- 浏览量、心意数保持不规则，避免明显的批量假数据感。
- 同一用户的表达保持人格一致。
- 不使用 `TEST`、`123`、`333` 等开发文本。
- 配图不是核心依赖；没有准备真实图片文件时，`image` 和 `has_image` 必须保持空值或 `false`。

## 6. 文件分工

- `01-演示用户与身份.md`：用户身份和人物设定。
- `02-海洋与天空内容池.md`：浮笺、飞笺及发布时间、场景、浏览量。
- `03-心意留言与开发组回信.md`：互动关系和文案。
- `04-森林时间胶囊.md`：时间胶囊三态及动态时间规则。
- `05-灵笺与Soul-Agent.md`：AI 对话、画像、匹配和代理对话。
- `06-后端启动重置与初始化改造指南.md`：如何将这些资料实现为启动 Seed。

## 7. 推荐演示顺序

`林间旅人进入 → 海洋打捞 → 点亮心意 → 天空接信并留言 → 我的页面查看私有回响 → 森林查看三态 → 新建一分钟胶囊 → 灵笺画像 → Soul Agent 匹配（可选）`
