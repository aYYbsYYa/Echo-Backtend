# 演示用户与身份

## 1. 主演示身份

```json
{
  "id": "demo_user_main",
  "nickname": "林间旅人",
  "birthday": "2000-01-01",
  "gender": "prefer_not_to_say",
  "region": "杭州",
  "avatar": "林"
}
```

人物设定：正在毕业和未来选择之间寻找方向，表达克制，重视真实体验，适合作为海洋、森林和灵笺三条故事线的共同主人公。

前端演示时应将本地身份固定为 `demo_user_main`，否则“我的”、胶囊和灵笺数据无法命中。

## 2. 辅助演示身份

```json
{
  "id": "demo_user_wind",
  "nickname": "晚风来信",
  "birthday": "1999-08-17",
  "gender": "prefer_not_to_say",
  "region": "南京",
  "avatar": "晚"
}
```

用途：提前为主演示身份的内容点赞、留言；也可以在双浏览器窗口演示作者与读者视角差异。

## 4. 人格一致性

| 用户 | 主要表达主题 | 语气 |
|---|---|---|
| 林间旅人 | 毕业、方向、自我允许 | 克制、反思 |
| 晚风来信 | 对陌生人的短暂善意 | 温和、简短 |
| 潮汐以北 | 工作、离开家乡 | 平静、成熟 |
| 月台尽头 | 远行、关系变化 | 有画面感 |
| 松针落下 | 创作、自我怀疑 | 细腻 |
| 云层背面 | 日常小确幸 | 轻盈 |
| 留一盏灯 | 疲惫、坚持 | 稳重 |
| 听鲸的人 | 孤独、失眠 | 安静 |
| 雨停之前 | 勇气、边界 | 真诚 |
| 迟到的星光 | 未来愿望 | 乐观但不喊口号 |

## 5. 约束

- 用户 ID 必须稳定，Seed 中不可调用随机 ID 生成器。
- `avatar` 保持单个汉字，与当前用户 API 的生成习惯一致。
- 生日只用于满足现有字段要求，不应在演示页面突出展示。
- 不创建手机号、邮箱、密码等项目当前不存在的字段。
