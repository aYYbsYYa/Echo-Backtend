## 3. 随机发现要求

- 主身份发现内容时，后端会排除 `demo_user_main` 自己的内容。
- 海洋和天空至少各保留 8 条非主身份内容，防止内容池过小、连续抽到同一条。
- 若后续希望演示完全可重复，应另做“演示发现顺序”功能；当前 `random.choice` 只能保证内容质量，不能保证抽取顺序。
- 不在 Seed 中给图片字段写不存在的文件名，否则 API 会返回无效图片地址。
