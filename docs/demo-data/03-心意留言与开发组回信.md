# 心意、留言与开发组回信

## 1. 互动原则

- 点赞记录只含 `id`、`item_id`、`user_id`。
- 留言对内容作者私有，读者之间不能看到彼此留言。
- 留言不邀请建立联系，不形成持续回复链。
- 主身份自己的内容需要更丰富的互动，确保“我的”页面有展示价值。

## 4. JSON 形态

```json
{
  "id": "demo_like_bottle_01_01",
  "item_id": "demo_bottle_01",
  "user_id": "demo_user_wind"
}
```

```json
{
  "id": "demo_comment_bottle_01_01",
  "item_id": "demo_bottle_01",
  "user_id": "demo_user_wind",
  "nickname": "晚风来信",
  "content": "慢一点也没有关系。你不是一张 offer，也不需要用一个结果解释完整的自己。",
  "created_at": "由 Seed 按相对时间生成"
}
```

## 5. 校验条件

- 每个 `item_id` 必须存在于 `bottles.json` 或 `planes.json`。
- 每个 `user_id` 必须存在于 `users.json`。
- 作者不能给自己的内容预置心意。
- 同一用户不能对同一内容出现两条点赞记录，否则切换点赞时行为会异常。
- 评论中的 `nickname` 与对应用户昵称保持一致。
